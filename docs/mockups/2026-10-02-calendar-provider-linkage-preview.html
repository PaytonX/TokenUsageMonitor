P2 方案二 · 核心变化

日历永远显示全部工具总量，数字和统计行不因点击卡片而改变。点卡片只改变视觉分层： 该 Provider 有用量的日子用它的品牌色着色并加亮描边，其余日子整体压暗到 ~22%。 「累计 / 峰值 / 活跃」下方追加一行该 Provider 自己的口径。

为什么不再切数据源

切数据源时，用户无法区分「日历变了」是因为点了卡片、还是因为口径本身不同。 总量恒定 + 只改透明度，可以让「这一天 MiniMax 烧了多少」和其他来源同屏对比—— 这是切换数据源永远做不到的。

14px 格子放不下的信息

构成占比不进格子，改为 tooltip 分层明细：总量 → 各 Provider 值 + 百分比。 数据来自 get_usage_history 已返回的 source/model 字段，后端零改动。

无按日数据的卡片怎么办

差分类 Provider（Kimi / OpenCode / Codex…）不进账本，点了不再静默回落到「全部工具」—— 那是撒谎。改为保持当前视图，并在卡片上标注「无按日数据」，高亮不生效。
