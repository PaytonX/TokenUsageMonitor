胶囊圆环：把「一个窗口」扩到「全部窗口」的两种方案

胶囊常态是 168×56 的透明窗口，圆环目前只显示 ring_window 选中的那一个窗口 （auto = 最吃紧的窗口）。下面两种方案都保持「不展开时仍然只有一枚圆环」， 区别在于额外信息放在哪里。虚线框表示 Tauri 窗口边界——浮层不能超出窗口， 展开必然意味着改窗口尺寸（现有 expandPill() 已经在做这件事）。

方案 A

悬停圆环 → 窗口明细

复用现有的「悬停展开」链路：胶囊长高，展开区从「每个账户一行」换成当前聚焦账户的三个窗口。

  • + 信息完整：5h / 周 / 月各自的已用、额度、重置时间都能放下。
  • + 不改变常态：收起时仍是一枚圆环，不占额外宽度。
  • + 与详情卡同一套语言，用户不用学新图例。
  • − 需要悬停/点击才看得到，不是一眼可读。
  • − 贴边态展开方向要按边处理（现有 expandPill 已解决）。
B1

三环同心

一枚 38px 圆环里画三条弧：内 5h、中 周、外 月；图例塞进 56px 主行，替掉账户名与大数字。

  • + 常驻可见，不需要悬停。
  • + 仍只占一枚环的位置，窗口宽度不变。
  • − 38px 下三条弧各约 3px，方向/长度都难分辨。
  • − 必须配图例；图例又挤掉了账户名。
  • − 色觉障碍用户无法区分弧线。
B2

三环并排

三个 22px 小环并排，各带窗口标签与百分比。阅读顺序最直白。

  • + 每个窗口独立、无需图例，一眼对应。
  • + 能塞进 168px 宽，不必改窗口几何。
  • − 必须挤掉账户名与「最吃紧窗口」的大数字。
  • − 22px 环 + 8px 标签，远看几乎只剩三个点。
  • − 想同时保留账户名就得加宽窗口，贴边定位要重算。
推荐：A，并把 B 作为「聚焦账户后的常驻摘要」的备选

现有 expandPill() 已经解决了「窗口长高、贴边方向、收起动画」三件事， A 只需要把展开内容从「所有账户各一行」改成「当前账户的三个窗口 + 重置时间」， 实现风险最低，也最符合现有详情卡的阅读方式。B1 的三条弧在 38px 下各约 3px， 实际使用中大概率仍然要靠图例，而图例已经把账户名挤掉了；B2 虽然能塞进 168px，但代价是账户名与「最吃紧窗口」的大数字一起消失，胶囊退化成三个仪表点。 若你更看重「不悬停也能看到」，建议单独在展开区做一个 2×2 的窗口摘要， 而不是把三个环塞进常态胶囊。
