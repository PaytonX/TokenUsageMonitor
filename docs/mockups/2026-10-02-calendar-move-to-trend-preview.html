联动没有丢，只是换了载体

日历离开总览后，卡片↔日历在 400px 窗口里物理上无法同屏。趋势页顶部的 provider 药丸条接替卡片成为高亮入口，与已有的「7天/30天/90天」区间按钮同构， 不额外占垂直空间。已建成的 calendar-linkage.ts（28 个测试）全部复用， 高亮配色逻辑一行不改。

三层分层的意义

总览 = 账户额度（还剩多少）· 趋势 = 用量历史（烧了多少、哪天）· 工具 = 工具维度（哪个工具烧的）。原来「额度卡片下挂一个工具口径的日历」 是维度错配，现在三者各归其位。

日历口径仍需注意

日历总量是本机工具 token（含 cache_read，占 78.6%），不是账户账单。 火山/OpenAI/xAI 的账户日账是另一套口径（服务端为准），仍走趋势页的口径下拉切换， 两者不相加。这与之前实测的结论一致。

已验证 / 未验证

本预览为静态交互稿：数据、配色、布局比例均取自真实账本与现有 tokens， 高亮交互已实现可点。真实窗口的换页动画、拖拽停靠、透明窗圆角需在 npm run tauri:dev 里实机确认，本稿无法覆盖。
